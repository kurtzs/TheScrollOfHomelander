# Mod Map

Everything below is relative to `mods\TheScrollOfHomelander` unless stated otherwise.

## Top Level

| Path | Role |
| --- | --- |
| `Config.lua` | Mod metadata, plugin declarations, every user-facing setting, setting groups, tags, update log |
| `Settings.Lua` | setting defaults file the game loader reads alongside `Config.lua` |
| `Build-Deploy.ps1` | Windows-only pipeline: compile both sides, write the manifest, optionally deploy; Linux uses [direct workers](../../taiwu-linux-development/SKILL.md) instead |
| `build-records\Frontend.json`, `build-records\Backend.json` | raw Roslyn worker JSON saved by the Windows pipeline (diagnostics, output paths) |
| `release-manifest.json` | Windows-pipeline record: source digest, per-file source hashes, game assembly fingerprints, plugin hashes; not regenerated by direct worker builds |
| `Plugins\Front`, `Plugins\Back` | build output and the exact files that get deployed |
| `Assets`, `GradeBackgrounds`, `icon.png` | Mod assets copied to the deployment destinations |
| `Scripts\Frontend`, `Scripts\Backend`, `Scripts\Shared` | source (see below) |

## Where A Change Belongs

| You want to change... | Edit |
| --- | --- |
| A user-facing toggle, slider, default, group, or the Mod version | `Config.lua` (+ the matching field in the side's `Plugin.cs`) |
| Which plugins the game loads | `Config.lua` `FrontendPlugins` / `BackendPlugins` |
| UI layout, controls, tooltips, colours, icons, list rendering | `Scripts\Frontend\Features\` |
| Feature state that survives a scene or view rebuild | `Scripts\Frontend\Shared\` |
| Authoritative rules, save/month-turn logic, item or character mutation | `Scripts\Backend\` (patch first, then a `*Service` if data is shared) |
| Names shared by both sides, or the bridge protocol version | `Scripts\Shared\ModProtocol.cs` |
| How patches are grouped, installed, and rolled back | `Scripts\Shared\ModPatchGroups.cs` |
| Plugin lifecycle, settings load, feature registration | `Scripts\Frontend\Plugin.cs`, `Scripts\Backend\Plugin.cs` |

## Shared Plumbing Worth Knowing

| Type | Responsibility |
| --- | --- |
| `Frontend\Shared\ModSession` | `MonoBehaviour` host: scene/session generation counter, `Reset()` on state change, generation-guarded `Delay` coroutines |
| `Frontend\Shared\AsyncSettingsSaveQueue` | single writer for the JSON stores, atomic replace, bounded retries |
| `Frontend\Shared\ModUserDataPaths` | resolves the runtime user-data directory and its legacy fallbacks |
| `Frontend\Shared\MakeGameApi` | typed access to the crafting APIs; `Validate()` runs before the `make` group is installed |
| `Frontend\Shared\MakeExecutionLifetime`, `MakePageDeferredActionQueue` | lifetime and deferred work for Mod-owned crafting coroutines |
| `Frontend\Shared\UiLayoutRefreshQueue`, `GamePerformancePatchLifecycle`, `ItemListRefreshCoordinator` | coalesced refresh and enable/disable orchestration for UI and performance patches |
| `Frontend\Shared\MemoryOptimizationSettingsStore` | persisted "remember last choice" state, per store key |
| `Frontend\Shared\ReflectionHelpers` | the one fallback for private game members; prefer it over new reflection |
| `Frontend\Shared\CharacterSearchResultData`, `Backend\Features\CharacterSearchResultData` | the two copies of the search DTO, one per side (the project has no shared DTO assembly) |
| `Backend\Features\AutoRepairService`, `CharacterSearchService` | reference implementations of a `DomainManager.Mod.AddModMethod` handler |
| `Backend\Recovered\` | recovered month-turn diagnostics and secret-information optimizations; treat names here as historical, verify against the live assembly before editing |

## Naming Consequences

`ModPatchGroups.Classify` derives a patch class's group from its class name, so the file and class name you choose decides which group installs it (see the table in `SKILL.md`). A class named `…Map…` or `…WorldState…` lands in `map`; `…Make…`/`…Repair…` in `make`; `…Exchange…`/`…Shop…`/`…Purchase…`/`…Transfer…` in `trade`; anything else in `ui`. Renaming a patch class therefore can move it between groups — check before renaming.
